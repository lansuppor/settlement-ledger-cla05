# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 收款可携带收款请求标识 `request_id`：以（租户, 订单标识, request_id）唯一；同一标识重复提交（含并发、重启后）只入账一次，返回首次登记的处理结果；同标识不同金额属内容冲突，返回 409 且不改账。
- 收款失败（超限、订单不存在、跨租户）不写入收款记录，也不占用请求标识；修正后用同一标识重新提交按新请求受理。
