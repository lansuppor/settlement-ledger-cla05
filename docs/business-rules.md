# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 收款请求可携带 `request_id` 作为去重身份：同一（租户, 订单, `request_id`）在任意时刻最多计入一次；重复提交返回首次的处理结果，不累加金额。
- 同一 `request_id` 以不同金额再次提交属于内容冲突，拒绝且不改变任何已收金额。
- 收款失败（超限、订单不存在、跨租户）不写入收款记录，也不占用 `request_id`；修正后可重新提交。
